# 灵儿 v1 产品重组与 UI 设计蓝图

> 本文档将 [GLOSSARY.md](../../GLOSSARY.md) 与 [产品脊柱](map.md) 的最新规划、灵儿现有功能盘点，以及参考图的设计语言有机整合为一份可直接指导原型与重构的统一方案。
> 配色锁定 **白、蓝、黑** 三基调；只服务主人一人；不写代码，不提前代替尚未关闭的 5 张规则细则票据拍板。

## 一、现状诊断：为什么现在感觉「散、重、不一致」

结合现有代码（`DashboardLayout.tsx`、`CompanionPages.tsx`、`companion.css`、`index.css` 等），灵儿目前存在三类结构性割裂：

1. **双套 UI 设计语言打架**
   - `companion.css`（今天 / 安排 / 洞察 / 报告 / 小确幸 / 记忆）：宋体衬线大标题（`STSong`）、靛蓝 `#435cd1`、淡紫蓝渐变背景、72px 纯图标窄侧栏。
   - `index.css` + Tailwind（对话 / 日记 / 历史 / 设置）：Apple / ChatGPT 风格无衬线、系统蓝 `#0071e3`、中性灰 `#f5f5f7`。
   - 切换菜单就像在两个不同软件之间跳转，视觉一致性断裂。
2. **导航膨胀且职责重叠（8 个一级入口 + 2 个二级隐藏页）**
   - `今天` 与 `安排（任务/习惯）`、`日记` 都在重复展示习惯打钩和情绪打分。
   - `洞察` 与 `成长周/月报` 双轨并存，且 `ReportsView` 与 `灵儿的观察` 依赖 AI 编造建议，与新脊柱「周和月只汇总，不编造建议」冲突。
   - `小确幸` 单占一级菜单，分散了主循环的注意力。
3. **核心体验断裂：清单与对话分离**
   - 新脊柱的核心交互是「预印清单 + 对话捕捉实时填入」，但目前在 `今天` 页打字发送后会直接跳走进入全屏 `ChatView`，清单立刻消失；同时「信号（三餐、睡眠、运动、身体、番茄钟个数）」「昨日一条调整」「晚间输出与明日调整」「主人自定义规则」在现有界面中完全缺失。

## 二、功能增减与重组矩阵（增 / 留 / 合 / 减 / 延后）

以新脊柱的唯一成功标准衡量：**能否让「一天」的正循环（记录 → 反馈 → 调整）顺滑转起来**。

| 动作 | 模块 / 功能 | 现状对应 | 调整方案与理由 |
| :--- | :--- | :--- | :--- |
| **新增** | **信号（Signal）预印格与额外信号** | 无（旧版只有情绪/精力） | 在「今天」清单中新增独立**信号**区块：单条格（睡眠、心情、精力、番茄钟自动计数）+ 多条格（三餐、运动、身体 + 额外信号如加餐）。与习惯严格分行，空槽经晚间确认后标为中性的「今天没有」。 |
| **新增** | **昨日调整置顶 & 晚间收口卡** | 无 | 「今天」顶部置顶展示昨天写下的那一条「调整」并可标记践行状态；底部提供「今日输出（一句自己的话）」与「明日调整（只改一件事）」两个单句槽位。 |
| **新增** | **规则（Rule）轻量管理与标记** | 无 | 允许主人用一句话添加简单规则（第一版零内置）；条件触发时只在当日清单与右栏给出克制的蓝色标记，不下说教建议。 |
| **新增** | **同屏「对话捕捉」常驻右栏** | `Today` 跳转 `ChatView` | 参照参考图右侧 `Ask Tempra` 面板，在「今天」右侧常驻灵儿对话/语音捕捉栏：主人随口说，灵儿实时写入左侧清单并显示 `✓ 已写入 …` 确认条；晚间自动切换为「一次一项」引导模式。 |
| **重构合并** | **今天（日视图）+ 日记回看** | `Today` + `JournalView` | 取消独立「日记」页；在主顶栏用 `< 今天 >` 切换任意日期即可查看或补录当天完整清单，保留 Markdown 导出按钮。 |
| **重构合并** | **汇总（周 / 月视图）** | `InsightsPage` + `ReportsView` | 合并为一个「汇总」视图，直接通过顶栏 `日 \| 周 \| 月` 分段胶囊切换。展示习惯矩阵、信号分布、番茄钟总计、调整践行记录与输出合集；**彻底移除 `ai_analysis` 与「灵儿的观察」建议文案**。 |
| **保留优化** | **番茄专注 & 桌宠联动** | `FocusPanel` + `PetWindow` | 保留番茄钟/正计时、全局顶条计时状态、桌宠伴随与完成提示；完成一轮番茄后**自动累计写入当日「信号 · 番茄钟个数」**，不再孤立存在。 |
| **保留优化** | **全屏对话 / 语音通话 / 历史** | `ChatView` + `VoiceCallOverlay` + `HistoryView` | 保留语音输入、实时语音通话、离线唤醒与对话历史管理（作为长聊与语音场景的展开视图），统一视觉至白蓝黑体系。 |
| **保留下沉** | **习惯库 / 任务池管理** | `PlanView`（`HabitsView` / `TasksPanel`） | 日常勾选用「今天」清单即可完成；新建/停用习惯、调整分类（淘汰「学习成长」命名）、查看稍后/已完成任务池，收口到统一的「习惯与任务」管理页（或侧栏二级视图）。 |
| **降级移除** | **小确幸（独立页面）** | `Joys`（一级导航） | 移出一级导航，不再维护插画罐子页；旧数据可归档至历史查看，日常好状态自然归入「信号 · 心情/身体」。 |
| **下沉** | **长期记忆** | `Memories`（一级导航） | 下沉至侧边栏底部「系统」区（与设置相邻），保留增删改查与跳转来源消息，保障透明可控，但不抢主循环权重。 |
| **保留统一** | **设置（大脑/语音/作息/唤醒/桌宠）** | `SettingsView` + `ScheduleCard` + `WakewordCard` | 全部现有工程能力完整保留，视觉重构为统一白蓝黑表单；作息 4 节点（早安/午间/晚间复盘/睡前）与「一天」循环对齐。 |
| **明确不做（v1 延后）** | 科学方法库、名人思维模型库、AI 资讯流、独立笔记与间隔回顾系统、自动走神监测、多用户 | — | 严格遵守 [产品脊柱](map.md) 边界，等主循环稳定后再讨论扩展。 |

## 三、信息架构与导航收敛

抛弃现有 `72px` 纯图标窄边栏（8 个无标签图标认知负担高），参照参考图升级为 **`228px` 清晰文字 + 线性图标侧边栏**，将入口收敛为简洁的两大分组：

```text
┌──────────────────────────────────┐
│ [■] 灵儿            个人正循环   │  ← 品牌头（几何蓝黑徽标 + 副标）
├──────────────────────────────────┤
│ [🔍 搜索或速记…            ⌘K ] │  ← 全局快捷指令：跳日期 / 搜记录 / 速记
├──────────────────────────────────┤
│ 循环                              │  ← 分组一：日常高频
│  [▣] 今天              3 待核对  │     (激活态：白底圆角卡 + 细边框 + 蓝图标)
│  [◫] 汇总                        │     (周 / 月事实聚合，与顶栏联动)
│  [◎] 番茄专注          25:00     │     (计时中右侧显示蓝色倒计时胶囊)
│  [💬] 对话与通话                  │     (全屏深聊 / 实时语音 / 历史)
│                                  │
│ 管理                              │  ← 分组二：低频配置
│  [☑] 习惯与任务                  │     (习惯增删改/分类 + 稍后任务池)
│  [⚡] 规则               2 启用   │     (主人一句话规则清单)
│  [◈] 记忆                        │     (长期记忆管理)
│  [⚙] 设置                        │     (模型/语音/作息/唤醒/桌宠)
├──────────────────────────────────┤
│ 今日焦点                          │  ← 化用参考图 Calendars 轻量状态区
│  [■] 昨日调整          待践行    │     纯黑小方框快速标记 / 查看
│  [■] 晚间复盘          21:30     │     一键开启或查看免打扰状态
├──────────────────────────────────┤
│ 今日循环进度               65%   │  ← 化用参考图 Focus goal 进度卡
│ 4 习惯 · 5 信号 · 3 番茄          │
│ ━━━━━━━━━━━────── (蓝灰细进度条)  │
├──────────────────────────────────┤
│ [●] 主人 · 服务在线    [桌宠][◐] │  ← 底部：服务状态点 + 桌宠显隐 + 深浅切换
└──────────────────────────────────┘
```

**便捷性收益**：
- 90% 的日常使用停留在 **「今天」** 一页内完成（看清单 + 对话填表 + 勾任务 + 开番茄 + 晚间收口）。
- 顶栏保留 `日 | 周 | 月` 三段胶囊，一眼切看今天、本周、本月，无需在侧边栏来回寻找「洞察」「报告」「日记」。
- `⌘K / Ctrl+K` 随时唤起命令面板：直接输入一句话记录、切到某一天、或一键开始 25 分钟番茄。

## 四、白 · 蓝 · 黑 视觉设计系统（参照参考图骨架）

全面替换 `companion.css` 的宋体与靛紫渐变，统一全站（含所有面板、表单、弹窗与桌宠卡片）为一套干净、克制、信息密度舒适的现代桌面工具美学。

### 1. 三基调色板（浅色主视觉 + 暗色同源）

参考图的高级感来自 **90% 纯净白灰表面 + 极克制的高对比黑 + 单一功能强调色**。我们将参考图的紫色系统性置换为冷静、通透的 **钴蓝（Blue）**，并与灵儿的蓝白水晶形象自然呼应：

| 角色 | 浅色令牌（默认） | 暗色令牌（同源） | 使用规范 |
| :--- | :--- | :--- | :--- |
| **应用底布（Canvas）** | `#F6F7F9` | `#0B0D12` | 最外层画布与卡片间隙，轻冷灰衬托白卡片 |
| **侧栏底色（Sidebar）** | `#FAFAFB` | `#0F1219` | 与主画布仅以 `1px` 细线分隔，不做渐变 |
| **卡片表面（Surface）** | `#FFFFFF` | `#151923` | 所有清单卡片、KPI 条、右栏对话容器 |
| **次级填充（Subtle）** | `#F2F4F7` | `#1D2331` | 搜索框、用户输入气泡、未激活胶囊、「今天没有」标签 |
| **细描边（Border Hairline）** | `#E6E8EC` | `#242B3B` | 卡片外框、KPI 竖向分割线、列表分隔线 |
| **强调描边（Border Hover）** | `#D0D5DD` | `#364158` | 悬停态按钮、聚焦边框 |
| **主墨黑（Ink Primary）** | `#111318` | `#F3F4F6` | 标题、KPI 大数字、正文主文字、**主 CTA 实心黑按钮**、勾选框 |
| **次墨灰（Ink Secondary）** | `#4B5563` | `#A1AAB8` | 辅助说明、习惯副标、次级操作文字 |
| **弱提示灰（Ink Muted）** | `#8A94A6` | `#647084` | 分组小标题、时间戳、空白信号占位 |
| **主品牌蓝（Blue Primary）** | `#2563EB` | `#3B82F6` | 激活导航图标、进度条、折线图/热力最高阶、聚焦外环、触发规则徽章 |
| **深蓝悬停（Blue Hover）** | `#1D4ED8` | `#60A5FA` | 蓝色链接与交互悬停态 |
| **中蓝数据（Blue Mid）** | `#60A5FA` / `#93C5FD` | `#2563EB` / `#1E40AF` | 热力矩阵中阶、习惯「部分完成」状态、次级曲线 |
| **柔蓝底 tint（Blue Tint）** | `#EFF6FF` / `#DBEAFE` | `rgba(59,130,246,0.14)` | 昨日调整置顶条底色、规则触发胶囊、AI 写入高亮闪烁 |

> **克制原则**：不引入参考图里多用户团队用的五颜六色头像圆点（粉/黄/绿/橙）；全站严格守住 **白、黑、蓝** 三基调。仅在删除二次确认或服务离线时保留极克制的暗红语义提示。

### 2. 排版与数字规范

- **字体族**：全面取消宋体（`STSong`/`SimSun`），统一为 `"Inter", -apple-system, BlinkMacSystemFont, "SF Pro Text", "PingFang SC", "Microsoft YaHei", sans-serif`。
- **等宽数字**：所有时间、KPI 数字、番茄倒计时、日期区间强制启用 `font-variant-numeric: tabular-nums`，确保数字跳动不抖动、表格纵向严格对齐。
- **字号层级**：
  - 页面主标题（H1）：`20px–22px`，`font-weight: 600`，`letter-spacing: -0.02em`（如参考图 `Design team` 般精炼，不再占用超大垂直空间）
  - 卡片标题（H2）：`14px–15px`，`font-weight: 600`
  - KPI 核心数字：`26px`，`font-weight: 600`，行高 `1.1`
  - 正文与清单行：`13.5px–14px`，行高 `1.55`
  - 元信息 / 分组标题 / 胶囊标签：`11.5px–12px`，`font-weight: 500`

### 3. 几何圆角、线框与阴影（参照参考图细节）

- **圆角阶梯**：外层主容器/大卡片 `14px`，内嵌子卡片与按钮 `10px`，微胶囊/标签/热力格 `6px–8px`，全圆角仅用于分段切换器或状态圆点。
- **以线代影**：常规卡片仅用 `1px solid #E6E8EC`（零阴影或 `0 1px 2px rgba(17,19,24,0.03)`）；只有悬浮气泡（Popover）、激活态导航白卡、模态框使用柔和抬升阴影 `0 10px 28px rgba(17,19,24,0.08)`。
- **双色按钮层级（直接汲取参考图精髓）**：
  - **主操作（Primary CTA）**：纯黑底 `#111318` + 纯白字（如 `确认写入`、`开始专注`、`开启晚间复盘`），沉稳高级，与蓝数据色不打架。
  - **次操作（Secondary）**：纯白底 `#FFFFFF` + `1px solid #E6E8EC` 细框 + 黑字（如 `今天没有`、`先跳过`、`导出`）。
  - **轻量强调（Accent Tint）**：浅蓝底 `#EFF6FF` + 主蓝字 `#2563EB`（如 `已触发`、`已写入清单`、`专注中`）。

### 4. Icon 设计规范

- **统一规格**：重整 `AppleIcons.tsx`，全站使用统一 `20×20` / `16×16` 视口、`1.5px` 精细圆头圆角线性图标（`stroke-linecap: round; stroke-linejoin: round`），几何比例简洁锐利，与参考图左侧导航图标风格完全对齐。
- **禁用重色块图标**：常规状态统一用 `#6B7280` 线条；激活态转为 `#2563EB` 蓝色线条（或在 `24px` 浅蓝 `#EFF6FF` 圆角底上呈现）；复选框采用参考图 `Calendars` 同款 **16×16 纯黑圆角实心方框 + 白色细对勾**。
- **品牌标识**：用一枚简洁的 **2×2 蓝黑几何圆角方阵**（致敬参考图左上角极简几何标，同时暗合灵儿「清单四块 / 水晶棱面」）作为侧栏主标，保留灵儿角色头像用于右栏对话与桌面悬浮宠。

## 五、核心页面布局与板块分布

### 页面 1：「今天」主工作台（核心闭环页）

完全采用参考图最经典的 **「顶栏 + 4 格一体 KPI 条 + 左主画布（64%）/ 右伴随栏（36%）」** 结构：

1. **顶栏（Header）**
   - 左：`今天`（或选中历史日期如 `11月21日 周六`）+ 副标 `第 12 天正循环 · 晚间复盘 21:30`。
   - 右：日期切换 `< 今天 >` · 分段开关 `[ 日 | 周 | 月 ]` · `导出 MD` 描边按钮 · 提醒铃铛。
2. **四格一体 KPI 条（单张白卡，三根 `1px` 细竖线均分）**
   - **习惯**：`4 / 6` + 柔蓝微胶囊 `67%` + 右侧 6 枚微圆点状态（完成实蓝 / 部分浅蓝 / 未核灰）。
   - **信号**：`5 / 7 已填` + 右侧 7 根迷你竖条（已填蓝 / 未填浅灰）。
   - **番茄钟**：`4 个 · 1h 40m` + 右侧迷你蓝色折线（近 7 天专注节奏）。
   - **今日任务**：`2 / 4 待办` + 右侧状态圆标（重要项以蓝点标出）。
3. **左侧主画布（今日预印清单，自上而下四块清晰分层）**
   - **区块 A · 昨日那一条调整（置顶聚焦条）**
     - 浅蓝微底 `#EFF6FF` + 左侧 `3px` 主蓝竖条，一行展示昨天定下的单点调整（例：`「23:00 把手机放到书桌充电，不再带进被窝」`），右侧两个轻量状态按钮：`已践行` / `未做到`。
   - **区块 B · 习惯（重复承诺）**
     - 清晰白卡，每行包含：习惯名称 + 轻量分类标签 + 近 7 天蓝色小方点微热力 + 右侧三态紧凑切换胶囊（`完成` / `部分` / `未做`）。
     - 严格只存承诺状态，绝不塞入餐食或睡眠数字。
   - **区块 C · 信号（量出或观察到的事实）**
     - 模块化双排网格，零冗长表单，支持点击轻补录，更主要靠右侧对话实时填入：
       - **每日单条（4 格紧凑横排）**：`睡眠`（如 `7.2h · 醒1次`）、`心情`（`4/5` 蓝点刻度）、`精力`（`3/5` 蓝点刻度）、`番茄钟`（`4 个`，标注「自动计时」，点击一键起钟）。
       - **每日多条（3 组横向标签流）**：`三餐`（预印 `早` / `午` / `晚` 三格 + `＋ 额外信号` 如加餐）、`运动`（如 `跑步 30m`）、`身体`（如 `肩颈微酸`）。
       - **中性空态规范**：白天未填显示虚线浅灰 `待记录`；晚间主人确认跳过或没有后变为中性灰胶囊 `今天没有`（绝不用红色或感叹号制造挫败感）。
   - **区块 D · 今日任务 & 晚间收口卡**
     - **今日任务**：极简行内速加框（回车即建）+ 纯黑圆角复选框列表，悬停出现快捷操作：`▶ 专注`（绑定该任务启动番茄）、`标重要`、`移至明天`。AI 手艺学习项自然以任务形式记在这里。
     - **晚间收口卡**：两行简洁输入槽——`今日输出`（用自己的话写一句今天学到的）与 `明日调整`（只定明天要改的一件事）。完成这两句后，卡片右上角亮起蓝色 `✓ 今日闭环`。
4. **右侧伴随栏（上下两张卡片，深度对应参考图右栏）**
   - **上卡 · 对话捕捉（灵儿）**
     - 标题行：`[灵儿微标] 灵儿` + 右上模式标签（白天为 `对话捕捉`，点击可一键切换 `晚间复盘`）。
     - 精简消息流：主人发消息用中性浅灰气泡 `#F2F4F7`，灵儿回复直接白底排布；**每当捕捉到记录，灵儿回复上方插入一条参照参考图 `✓ Checked 6 calendars` 风格的极简蓝/黑状态条**：
       > `✓ 已填入 · 信号·午餐（牛肉面）· 信号·运动（跑步30m）· 习惯·跑步（完成）` `[撤销]`
       同时左侧对应清单项轻闪一次淡蓝光晕（`#EFF6FF`，600ms 渐隐），让「说出来就填上」有即时、踏实的掌控感。
     - **晚间复盘模式（一次只问一项）**：对话区顶部挂出进度条（如 `第 2 / 5 项 · 信号·晚餐`），下方给出清晰双按钮：纯黑主按钮 `确认写入` + 白底描边次按钮 `今天没有 / 先跳过`，彻底告别压迫感表单。
     - 底部紧凑输入条：文字输入 + 语音麦克风 + 实时通话图标 + 纯黑发送键。
   - **下卡 · 规则标记 & 下一提醒**
     - 化用参考图 `Open requests` 列表样式，极度干净：
       - 已触发的规则行：规则原文 + 右侧浅蓝胶囊 `已触发`（如 `睡眠少于 6 小时` → 触发自今日睡眠 `5.5h`）。
       - 下一个定时节点：如 `21:30 晚间复盘` + 免打扰快捷开关。
       - 若主人尚未添加规则，仅展示一句轻提示与 `＋ 用一句话加条规则`。
